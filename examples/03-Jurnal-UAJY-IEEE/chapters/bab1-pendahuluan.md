# PENDAHULUAN

Pendidikan robotika memerlukan media visualisasi praktis. Peserta didik dituntut memahami pergerakan kinematika serta mekanisme perangkat keras secara spasial [@vaughan2011multimedia]. Akan tetapi, tingginya biaya pengadaan laboratorium fisik di berbagai institusi menjadi kendala utama pemerataan teknologi otomasi.

Teknologi grafis web modern berbasis WebGL kini memungkinkan simulasi interaktif tiga dimensi dijalankan langsung pada peramban tanpa instalasi perangkat lunak tambahan [@dirksen2013learn]. Kendati demikian, integrasi antara simulasi spasial real-time dan portal manajemen operasional multi-role terpadu masih sangat terbatas.

Penelitian ini menjawab tantangan tersebut. Platform web edukasi robotika bervisualisasi 3D dirancang menggunakan metodologi Multimedia Development Life Cycle (MDLC) versi Luther-Sutopo [@luther1994authoring].
