# Migrasi ke v4.0.0

Versi 4.0.0 mengganti nama keluaran audit stylometri agar tidak menyiratkan deteksi atau probabilitas penggunaan AI. Perubahan ini memengaruhi skrip dan aplikasi yang membaca JSON dari `scripts/audit-forensics.py` atau `laporan audit --json`.

| Sebelumnya | v4.0.0 | Arti |
| --- | --- | --- |
| `summary.max_ai_probability` | `summary.max_pattern_score` | Skor pola tertinggi dalam dokumen |
| `files[].ai_probability` | `files[].pattern_score` | Skor pola untuk satu berkas |

Perbarui konsumen JSON agar menggunakan nama field baru. Nilainya adalah skor heuristik untuk pola tulisan; nilainya tidak dapat ditafsirkan sebagai probabilitas, bukti penggunaan AI, atau bukti kepengarangan.

Contoh:

```python
result = json.loads(output)
max_score = result["summary"]["max_pattern_score"]
```

Opsi `--fail-on-ai` tetap tersedia sebagai alias kompatibilitas untuk sementara. Gunakan `--strict` pada skrip baru. Mode ini gagal saat skor pola melewati ambang audit yang dikonfigurasi; mode ini tidak mendeteksi AI.
